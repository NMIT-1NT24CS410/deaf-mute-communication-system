ISL Communication Assistant

Bridging the gap between the deaf/mute community and the hearing world. This application uses AI-powered gesture recognition to translate Indian Sign Language into text and speech, as well as text/voice back into visual sign language.

Launch Assistant Workspace

Module 1: Sign to Text/Speech

Allows users to show Indian Sign Language (ISL) gestures in front of their webcam. The AI extracts hand landmarks in real-time, translates them into characters/words, and plays them aloud using text-to-speech.

Module 2: Text/Voice to Sign

Allows a hearing person to type text or speak using the microphone. The application parses the input and runs an animated sign language slideshow showing the corresponding ISL gestures.
