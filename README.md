# ISL Communication Assistant — Final Year Project
### Deaf & Mute People Communication App

---

## Project Overview

This app helps deaf and mute people communicate in two ways:

| Module | Description |
|--------|-------------|
| **Module 1** | Sign Language → Text + Speech (webcam detects ISL gestures, converts to spoken words) |
| **Module 2** | Text / Speech → Sign Language (hearing person types or speaks, app shows ISL signs) |

**Tech Stack:** Python · MediaPipe · TensorFlow/Keras · OpenCV · pyttsx3 · SpeechRecognition

---

## Setup Instructions

### 1. Install Python 3.9 or 3.10
Download from https://www.python.org/downloads/

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Get the ISL Dataset (choose one option)

**Option A — Kaggle Dataset (Recommended)**
1. Go to: https://www.kaggle.com/datasets/prathumarikeri/indian-sign-language-isl
2. Download and extract to a folder called `dataset/`
3. Each subfolder should be named A, B, C ... Z, 1, 2 ... 9

**Option B — Collect your own (custom)**
```bash
python step1_collect_dataset.py
```
Show each ISL sign in front of your webcam. Press S to start collecting for each class.

---

## Run the Project (Step by Step)

### Step 1 — Collect dataset
```bash
python step1_collect_dataset.py
```
_(Skip if using Kaggle dataset)_

### Step 2 — Extract hand landmarks
```bash
python step2_extract_landmarks.py
```
Reads all images from `dataset/`, extracts 21 MediaPipe hand landmarks → saves `landmarks.csv`

### Step 3 — Train the model
```bash
python step3_train_model.py
```
Trains a Neural Network → saves:
- `model/isl_model.h5` (Keras model)
- `model/label_encoder.npy` (class names)
- `model/isl_model.tflite` (for mobile)

### Step 4 — Run the app
```bash
python main_app.py
```

---

## Controls (Module 1 — Sign Detection Window)

| Key | Action |
|-----|--------|
| SPACE | Add detected letter to current word |
| ENTER | Speak the word aloud |
| BACKSPACE | Delete last letter |
| C | Clear current word |
| Q | Quit |

## Project Folder Structure

```
isl_project/
├── requirements.txt
├── main_app.py                  ← Run this to start the app
├── step1_collect_dataset.py     ← Collect ISL images (optional)
├── step2_extract_landmarks.py   ← Extract MediaPipe landmarks
├── step3_train_model.py         ← Train the classifier
├── step4_sign_to_speech.py      ← Module 1: Sign → Speech
├── step5_text_to_sign.py        ← Module 2: Text → Sign display
├── dataset/                     ← ISL images (A-Z, 1-9)
│   ├── A/
│   ├── B/
│   └── ...
├── isl_signs/                   ← Reference sign images for Module 2
│   ├── A.jpg
│   ├── B.jpg
│   └── ...
├── landmarks.csv                ← Generated by step2
└── model/
    ├── isl_model.h5             ← Trained model
    ├── label_encoder.npy        ← Class labels
    ├── isl_model.tflite         ← Mobile model
    └── training_history.png     ← Accuracy/loss graph
```

- Training accuracy: ~95–99%
- Real-time detection: works at 15–30 FPS
- Supported signs: A–Z (26 alphabets) + 1–9 (9 digits) = 35 classes
